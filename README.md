# 🍺 Brewery Store App

A web-based application that simulates an online brewery store, allowing users to browse products and manage purchases in a simple and intuitive interface.

## 📌 Overview

This project was developed as part of a university assignment and demonstrates the implementation of a basic e-commerce platform using PHP.

The application focuses on core functionalities such as product display, user interaction, and structured backend logic.

---

## 🚀 Features

* 🛒 Product listing and browsing
* 📦 Basic store structure for managing items
* 👤 User interaction (navigation, selection, etc.)
* 🧾 Simple e-commerce workflow simulation
* 📊 Backend logic implemented in PHP

---

## 🛠️ Technologies Used

* **PHP** – Backend logic
* **HTML5** – Structure
* **CSS3** – Styling
* **JavaScript** – Interactivity (if applicable)
* **MySQL** *(optional depending on implementation)*

---

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/Douggsv/brewery-store-app.git
```

2. Move the project to your local server directory:

* XAMPP → `htdocs/`
* WAMP → `www/`

3. Start your local server (Apache + MySQL)

4. Open your browser and go to:

```
http://localhost/brewery-store-app
```
